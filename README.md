# رواق — متجر العبايات

نموذج أولي (Prototype) كامل لمتجر عبايات نسائية فاخر، بتصميم داكن وذهبي، عربي من اليمين لليسار.

## التشغيل
- افتحي `index.html` مباشرة في المتصفح (Chrome / Edge / Safari). لا يحتاج تثبيت أي شيء.
- أو شغّليه من سيرفر محلي: `py -3 -m http.server 5500` ثم افتحي `http://localhost:5500`.
- يحتاج اتصالًا بالإنترنت لتحميل الخطوط والصور ومكتبات الحركة. لو لم تُحمّل مكتبات الحركة يعمل الموقع بالكامل بدونها.

## الصفحات
الرئيسية · المتجر (فلاتر كاملة) · صفحة المنتج · المفضلة · حسابي · تتبع الطلب · تأكيد الطلب · حكايتنا · تواصلي معنا · الأسئلة الشائعة · الشحن · الاستبدال.
كل صفحة لها رابط مباشر، مثل `#/product/3` أو `#/shop?cat=embroidered`.

## للتجربة
- أكواد خصم: `RAWAQ10` (10%)، `WELCOME15` (15% فوق 1500 ج.م)، `VIP200` (200 ج.م فوق 2500 ج.م).
- الحساب وإتمام الطلب تجريبيان: البيانات تُحفظ في المتصفح فقط ولا يتم أي دفع.
- حالة الطلب في صفحة التتبع تتقدم خطوة كل دقيقتين لعرض المراحل.
- اختصار البحث: اضغطي `/` أو `Ctrl + K`.

## التعديل
- **المنتجات والأسعار:** `js/data.js` ← `PRODUCTS`.
- **الصور:** `js/data.js` ← `PHOTOS`. ضعي رابط صورة كاملًا مكان أي معرّف لاستخدام صور العميل.
- **رقم واتساب والبريد:** `js/data.js` ← `STORE_INFO`، وروابط `wa.me` في `index.html`.
- **الألوان والخطوط:** أول جزء في `css/style.css` (`:root`).

## الملفات
```
index.html        كل الصفحات والنوافذ
css/style.css     التصميم
js/data.js        البيانات
js/store.js       السلة، المفضلة، الطلبات، الحساب (localStorage)
js/motion.js      الحركة (شاشة البداية، التمرير الناعم، GSAP)
js/app.js         التوجيه وعرض الصفحات والتفاعل
```

الصور من Unsplash (للعرض فقط) — استبدليها بصور المنتجات الحقيقية قبل الإطلاق.
