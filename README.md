# شَهد — متجر الحلويات الشرقية

نموذج أولي (Prototype) كامل لمتجر حلويات شرقية وغربية، بتصميم فاتح ومبهج (كريمي، وردي، فستقي وعسلي)، عربي من اليمين لليسار.
مبني على نفس هيكل ومميزات موقع «رواق»، مع تعديل المحتوى والألوان بالكامل.

## التشغيل
- افتح `index.html` مباشرة في المتصفح (Chrome / Edge / Safari). مش محتاج تثبيت أي حاجة.
- أو شغّله من سيرفر محلي: `py -3 -m http.server 5500` وافتح `http://localhost:5500`.
- الخطوط ومكتبات الحركة بتتحمل من الإنترنت. لو متحملتش الموقع بيشتغل عادي من غيرها.

## الصفحات
الرئيسية · المنيو (فلاتر بالمكوّن والمناسبة والسعر) · صفحة الصنف · المفضلة · حسابي · تتبع الطلب · تأكيد الطلب · حكايتنا · كلّمنا · الأسئلة الشائعة · التوصيل · ضمان الجودة.
كل صفحة ليها رابط مباشر، زي `#/product/1` أو `#/shop?cat=konafa`.

## الأقسام
كنافة وقطايف · بسبوسة وهريسة · بقلاوة وجلاش · كحك ومعمول وبسكويت · تورت وحلويات غربي · كاسات وحلويات سريعة.
كل صنف ليه أوزان (ربع / نص / كيلو) أو أحجام (تورتة صغيرة / وسط / كبيرة، علب، كاسات) والسعر بيتغير حسب الاختيار.

## للتجربة
- أكواد خصم: `SHAHD10` (10%)، `WELCOME15` (15% فوق 500 ج.م)، `SWEET100` (100 ج.م فوق 1200 ج.م).
- «دليل الكميات»: اكتب عدد الضيوف وعدد الأصناف ويقترح عليك الوزن وحجم التورتة.
- الحساب وإتمام الطلب تجريبيين: البيانات بتتحفظ في المتصفح بس ومفيش دفع حقيقي.
- حالة الطلب في صفحة التتبع بتتقدم خطوة كل دقيقتين.
- اختصار البحث: `/` أو `Ctrl + K`.

## التعديل
- **الأصناف والأسعار:** `js/data.js` ← `PRODUCTS`. الأوزان ومضاعفات السعر في `SIZE_OPTIONS`.
- **الصور:** الرسومات الحالية في `assets/sweets/` (SVG). لاستخدام صور حقيقية ضع رابط الصورة في `PHOTOS` داخل `js/data.js`، مثال: `'konafa-cream': 'https://.../konafa.jpg'`.
- **إعادة توليد الرسومات:** `python3 tools/make-sweets.py assets/sweets`.
- **رقم واتساب والبريد:** `js/data.js` ← `STORE_INFO`، وروابط `wa.me` في `index.html`.
- **الألوان والخطوط:** أول جزء في `css/style.css` (`:root`).

## الملفات
```
index.html          كل الصفحات والنوافذ
css/style.css       التصميم
js/data.js          البيانات (الأصناف، الأقسام، الأوزان، التوصيل، الكوبونات)
js/store.js         السلة، المفضلة، الطلبات، الحساب (localStorage)
js/motion.js        الحركة (شاشة البداية، التمرير الناعم، GSAP)
js/app.js           التوجيه وعرض الصفحات والتفاعل
assets/sweets/      رسومات الحلويات
tools/make-sweets.py  مولّد الرسومات
```
